# VS Code: handy shortcuts

Only shortcuts I'm still learning. The ones I already remember and use well are left out on purpose.

## Moving around (French keyboard)

| Action | Keys |
|---|---|
| End of line | `Fn` + `FIN` |
| Start of line | `FIN` |
| Select to end of line | `Shift` + `Fn` + `FIN` |
| Open a file by typing part of its name | `Ctrl` + `P` |
| Go to a line number | `Ctrl` + `G` |
| Jump to a heading in `.md`, or a function in code | `Ctrl` + `Shift` + `O` |

## Editing

| Action | Keys |
|---|---|
| Move the line up / down | `Alt` + `↑` / `Alt` + `↓` |
| Delete the line | `Ctrl` + `Shift` + `K` |
| Select all matches of the current word, to edit them at once | `Ctrl` + `Shift` + `L` |
| Format the whole file | `Ctrl` + `Shift` + `I` |

## Markdown preview

| Action | Keys |
|---|---|
| Open preview in the current tab | `Ctrl` + `Shift` + `V` |
| Open preview on the right side | `Ctrl` + `K`, release, then `V` |
| Close the side preview | `Ctrl` + `2`, then `Ctrl` + `W` |
